# 🚀 Руководство по развёртыванию QazTender Radar (24/7 в Интернете)

Данный проект полностью готов к развёртыванию в интернете и непрерывной работе 24 часа в сутки, 7 дней в неделю.

---

## 🏗 Архитектура боевого сервиса:
1. **Веб-платформа (Next.js / Vinext)**: работает на порту `3000` (дашборд, воронка, API);
2. **Адаптивный Смарт-планировщик (sync-scheduler.mjs)**: опрашивает Госзакупки каждые 15 минут в рабочие часы;
3. **Telegram Бот (@QazTendeRadar_bot)**: принимает команды, меняет стадии, шлёт моментальные пуши;
4. **База данных SQLite**: сохраняет 600+ тендеров, фильтры, заметки и чек-листы без потери данных.

---

## 🌟 Вариант 1: Развёртывание на VPS сервере (Рекомендуемый для РК)

Самый надёжный и стабильный вариант для Казахстана (стоимость: от 1 500 до 3 000 ₸ в месяц / $3–$5).
Подойдут провайдеры: **Timeweb Cloud**, **Beget**, **Hetzner**, **DigitalOcean**, **PS.kz**.

### Шаг 1. Аренда сервера
* Выберите тариф с **Ubuntu 22.04 / 24.04** (1-2 CPU, 2 GB RAM).

### Шаг 2. Установка Node.js и PM2 (или Docker)
Подключитесь к серверу по SSH и выполните:
```bash
# Обновление пакетов и установка Node 22 + PNPM + PM2
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs git
sudo npm install -g pnpm pm2
```

### Шаг 3. Клонирование и запуск проекта
```bash
# Клонируем проект (или загружаем архив)
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> qaztender
cd qaztender

# Устанавливаем зависимости и собираем проект
pnpm install
pnpm run build

# Запускаем все процессы (веб-сайт + синхронизатор + Telegram бот) в PM2:
pm2 start ecosystem.config.cjs

# Сохраняем автозапуск при перезагрузке сервера:
pm2 save
pm2 startup
```

### Шаг 4. Настройка Nginx и бесплатного SSL-сертификата (HTTPS)
```bash
sudo apt install -y nginx certbot python3-certbot-nginx

# Создаем конфиг /etc/nginx/sites-available/qaztender
# с проксированием на http://127.0.0.1:3000
# и выпускаем SSL:
sudo certbot --nginx -d your-domain.kz
```

## 🐳 Вариант 2: Запуск через Docker Compose (В 1 команду)

Если на сервере установлен Docker:
```bash
# 1. Запуск всех сервисов в фоновом режиме:
docker compose up -d --build

# 2. Проверка работы:
docker compose logs -f
```

## ⚡ Переключение Telegram-бота на боевой Webhook

Когда у вас появится публичный домен с HTTPS (например, `https://qaztender.kz`), выполните одну команду для мгновенной доставки сообщений через Webhook:
```bash
node scripts/set-webhook.mjs https://qaztender.kz
```

## 📊 Мониторинг и управление процессами:
* Проверить статус: `pm2 status`
* Посмотреть логи в реальном времени: `pm2 logs`
* Перезапустить: `pm2 restart all`
